# Sistema de Gestión de Tareas con API y Base de Datos

## Descripción
Este proyecto consiste en una API REST desarrollada en Flask que permite el registro de usuarios, inicio de sesión con contraseñas hasheadas y acceso a un panel de tareas. Incluye un cliente de consola para probar los endpoints.

## Requisitos Previos
- Python 3.x
- Librerías: `flask`, `requests`
